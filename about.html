About

Chen Erjian

First-year Computer Science at Hainan Bielefeld University of Applied Sciences. This site is my coursework for Web Technologies — six pages, written one file at a time, no framework and no build step.

What is here

A collection of quotes I keep rereading, six project ideas with the person each one is for, a machine that switches itself off, and this page — which is mostly an excuse to explain the other three.

How it is built

Pages
6 — home, quotes, projects, machine, about, contact
Stylesheets
2 — styles.css for pages, nav.css for the shared bar and footer
Scripts
2 — parts.js injects the navigation, machine.js runs the toys
Framework
None. Plain HTML, CSS and JavaScript
Hosting
GitHub Pages, published from the main branch

Two decisions

The navigation is written once. nav.html holds a bare <nav> fragment and parts.js fetches it into every page, so adding a page means editing one file instead of six. The same fetch loads footer.html. It also means the pages must be opened over HTTP — fetch() is blocked on file://.

One palette, no colour. Black, white and three greys. Every block on this site is one of those five values, which makes the layout carry the design instead of the other way round.

What I would change

The quotes page should filter by author. The machine could keep a small history of failed attempts. And the whole site should probably be one page with sections and scroll snapping — but six pages is what the course asked for, and it is the honest version of what I can build today.
